## Money Flow Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                      Revenue Sources                         │
└─────────────────────────────────────────────────────────────┘
         │                    │                    │
         ▼                    ▼                    ▼
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│   Hosting    │    │  Co-hosting  │    │   Vendor     │
│   Revenue    │    │   Revenue    │    │   Services   │
└──────┬───────┘    └──────┬───────┘    └──────┬───────┘
       │                   │                   │
       └───────────────────┼───────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                   Revenue Processing                         │
│                                                              │
│  1. Deduct Platform Fee (e.g., 10%)                         │
│  2. Pay Vendor Flat-Rate Fees                               │
│  3. Split Remaining Revenue:                                │
│     - Host Share (e.g., 50%)                                │
│     - Co-Host Share(s) (e.g., 50% split among co-hosts)    │
└──────────────────────────┬──────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                        Wallet                                │
│                  (Single Source of Truth)                    │
│                                                              │
│  ┌────────────────────────────────────────────────────────┐ │
│  │  Available Balance: $1,234.56                          │ │
│  │                                                         │ │
│  │  Earnings by Source:                                   │ │
│  │  - Hosting:     $800.00                                │ │
│  │  - Co-hosting:  $200.00                                │ │
│  │  - Vendor:      $234.56                                │ │
│  │                                                         │ │
│  │  Pending Payouts: $100.00                              │ │
│  └────────────────────────────────────────────────────────┘ │
└──────────────────────────┬──────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                    Withdrawal Actions                        │
│                                                              │
│  → Bank Transfer                                            │
│  → Mobile Money                                             │
│  → Other Payment Methods                                    │
└─────────────────────────────────────────────────────────────┘
```

## Separation of Concerns

```
┌─────────────────────────────────────────────────────────────┐
│                        DISCOVERY                             │
│                         (Public)                             │
│  ┌──────────────────────┬──────────────────────┐           │
│  │      Home Tab        │    Vendors Tab       │           │
│  │  - Event Feed        │  - Vendor Marketplace│           │
│  │  - Trending          │  - Search Services   │           │
│  │  - Search            │  - Filter Categories │           │
│  │  - Browse Hosts      │  - View Profiles     │           │
│  └──────────────────────┴──────────────────────┘           │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                       MANAGEMENT                             │
│                        (Private)                             │
│  ┌──────────────────────┬──────────────────────┐           │
│  │   My Events Tab      │    Profile Tab       │           │
│  │  - Guest View        │  - Settings          │           │
│  │  - Host View         │  - Role Upgrades     │           │
```
